# FrameX 3.0.0 — отчёт проверки

Дата: **18 октября 2026** (часовой пояс пользователя).

## Что действительно собрано

- Настоящий Windows x64 GUI **FrameX.exe**, не переименованный Python/BAT-файл.
- Встроенные CPython 3.11.9, Tcl/Tk 8.6.12 и библиотеки; отдельная установка Python пользователю не требуется.
- Настоящий **FrameX-3.0.0-Setup.exe**: Unicode NSIS 3.11, сжатие LZMA, выбор компонентов и папки, ярлыки, запись удаления, деинсталлятор и запуск после установки.
- Оболочка NSIS — стандартный PE32 bootstrap, устанавливающий **x64-приложение**. Установщик проверяет наличие Windows 10+ x64; это не 32-битная версия FrameX.
- Права установщика — administrator, установка для всех пользователей; путь по умолчанию `C:\Program Files\FrameX`.
- Приложение/установщик без платной подписи кода. Реакция SmartScreen на скачанный файл на реальной Windows не тестировалась.

## Границы проверки — важно

Среда сборки/проверки: Linux + **Wine 10**, Windows CPython x64 и Windows API, виртуальный экран Xvfb 1280×1024. Для проверки инсталлятора установлен также Wine32; Windows Python и само приложение — x64. Исходный код устанавливается/пакуется PyInstaller 6.22.3 под Windows Python; установщик компилируется NSIS.

**Это не испытание на физическом ПК с Windows и запущенной игрой.** Не подтверждены: реальный ETW-захват кадров, игровые FPS/frametime, работа античита, физические NVIDIA-датчики, настоящие диалоги UAC, все масштабы DPI/мониторы и поведение Explorer/SmartScreen на пользовательской Windows. Wine сам по себе эти сценарии полноценно не воспроизводит.

Эксклюзивный fullscreen не поддерживается архитектурой внешнего HUD; нужен оконный/безрамочный режим. CPU/RAM берутся из доступных датчиков, GPU/кадры без данных показаны «—».
