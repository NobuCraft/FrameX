# FrameX 3.0.0

Мониторинг игр для **Windows 10/11 x64**: автоматическое распознавание игры, FPS/frametime, компактный HUD, меню трея и настраиваемый интерфейс.

## Установка для пользователя

1. Запустите **FrameX-3.0.0-Setup.exe** и подтвердите запрос Windows.
2. Выберите компоненты и **папку установки**. Папка по умолчанию — `C:\Program Files\FrameX`.
3. Нажмите «Установить», затем «Готово». На последней странице можно запустить программу.
4. В дальнейшем используйте ярлык **FrameX** или **FrameX.exe** в выбранной папке.

**Устанавливать Python, запускать BAT или собирать программу не нужно.** Интерпретатор и библиотеки уже находятся внутри установленного приложения. Не перемещайте отдельно FrameX.exe: рядом необходима папка `_internal`.

Установщик создаёт ярлык в меню «Пуск», по выбору — на рабочем столе, и запись для удаления в настройках Windows. Приложение не имеет платного сертификата подписи кода: издатель в SmartScreen может быть неизвестным. Это не подтверждает безопасность файла; сверяйте SHA-256 с поставленным файлом контрольных сумм и проверяйте источник загрузки. Не отключайте антивирус ради установки.

## Смена интерфейса внутри программы

Откройте слева **«Интерфейс»**:

- **4 темы:** Аметист, Ночь, Графит и Светлая;
- **5 акцентов:** фиолетовый, синий, мятный, розовый и янтарный;
- **2 вида меню:** обычное с подписями или компактное с иконками;
- кнопка сброса оформления.

Изменения применяются сразу к основному окну, меню трея и HUD и сохраняются при закрытии. Стрелка вверху левого меню также переключает обычную/компактную навигацию. Размер, прозрачность, показатели и компоновку самого HUD настраивайте в разделе **«Оверлей»**.

## Игровая статистика

На старте включён автоматический захват. Для ETW/PresentMon понадобятся права администратора: подтвердите отдельный запрос, если приложение запущено без них. Затем откройте игру в **оконном или безрамочном режиме**. Ручной выбор процесса не обязателен: FrameX учитывает активное окно, графическую активность, известные игры и отсекает браузеры/лаунчеры.

Доступны FPS, frametime, 1% low, график времени кадра, CPU, RAM, а при поддержке NVIDIA NVML — загрузка/температура/память GPU. Это не инжектор RTSS и не полная замена MSI Afterburner.

- Отсутствующие значения показаны как **«—»**, а не случайные или выдуманные цифры.
- AMD/Intel GPU через NVML не поддерживаются: соответствующие значения могут отсутствовать.
- Датчики CPU/RAM остаются реальными и без кадров игры.
- 1% low считается по доступному скользящему окну кадров; не сравнивайте его напрямую с измерениями по всей игровой сессии.
- CSV — секундная сводка до 3600 последних замеров, а не полный покадровый трассировочный файл.
- Настоящий эксклюзивный fullscreen, защищённые экраны и некоторые античиты могут не позволять внешний HUD. Используйте безрамочный режим. Никакого обхода античита нет.
- Неизвестную игру при необходимости можно добавить по имени EXE в «Игры»; это необязательная настройка исключения, а не обязательный выбор процесса при каждом запуске.

## Если HUD не виден

1. Нажмите **«Показать мониторинг»** или **F8**: HUD принудительно остаётся видимым даже до появления FPS.
2. В настройках используйте **«Вернуть HUD на экран»**. После смены монитора координаты ограничиваются текущим экраном.
3. Проверьте, что игра в оконном/безрамочном режиме и разрешён запрос прав для захвата.
4. **F9** включает/выключает блокировку HUD и пропуск кликов. Если F9 занята, приложение не включает опасную блокировку без возможности её снять.
5. Откройте **«Диагностика HUD»**, сохраните отчёт и передайте его при обращении.

Можно проверить только окно, не запуская ETW/UAC: `FrameX.exe --overlay-test`. Это дополнительный режим, а не обязательный способ запуска. В нём не должно быть искусственных значений FPS.

Крестик сворачивает программу в трей, когда значок трея доступен. Полный выход — через **«Выход»** в трее или настройки. Кнопка **«Наш Дискорд»** открывает https://discord.gg/qHabsmgKVP . Discord не связан с разработкой приложения.

## Настройки и удаление

Настройки и отчёты находятся в `%APPDATA%\FrameX`. При первом запуске существующие настройки GameStats Overlay импортируются, если у FrameX ещё нет собственного файла. Старый файл не удаляется.

Удаление: «Параметры Windows → Приложения → FrameX → Удалить» или `Uninstall.exe` в папке установки. Сначала полностью закройте FrameX, включая трей. Личные настройки сохраняются; при необходимости удалите `%APPDATA%\FrameX` самостоятельно. Удаление не должно затрагивать посторонние файлы в выбранной папке.

## Проверки этой сборки

- 73 модульных теста и GUI smoke-тест;
- 40 сочетаний тем/акцентов/навигации, 6 страниц и HUD;
- настоящий Windows x64 EXE, упакованный PyInstaller с CPython 3.11.9;
- запуск упакованного EXE, видимость HUD и регистрация трея проверяются в Wine;
- установщик NSIS проверяется отдельно: выбор папки, установка, запуск EXE и удаление.

Подробные результаты — `QA_REPORT.md` в исходниках релиза. **Wine не заменяет проверку на реальной Windows с игрой. Фактический игровой ETW/FPS, античит, аппаратные GPU-датчики, UAC и все конфигурации мониторов на реальном компьютере здесь не подтверждены.**

## Для разработчика (не нужно пользователю установщика)

Исходники лицензированы MIT. Для собственной сборки нужны Windows x64, Python 3.11 x64 с Tcl/Tk и NSIS 3.x Unicode. Установите зависимости из `requirements.txt` и `requirements-build.txt`. Затем:

```text
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm --clean FrameX.spec
python scripts/prepare_payload.py
makensis installer/FrameX.nsi
```

Либо используйте `build_windows.bat` — **только как разработчик**. Результат: `release/FrameX-3.0.0-Setup.exe`. Обычный пользователь получает готовый установщик. `run_windows.bat` оставлен исключительно для запуска исходников разработчиком.

`FrameX.exe --self-test` выполняет автоматическую проверку GUI, записывает `%APPDATA%\FrameX\self-test.json` и закрывается; ETW не запускается. Для изолированной проверки задайте переменную окружения `FRAMEX_CONFIG_DIR` с отдельной папкой. Тест изменяет настройки тестового профиля, поэтому для своего обычного профиля используйте отдельную папку.

LGPL-библиотека pystray хранится обычными заменяемыми `.py` в `_internal/pystray`, а не закрыта внутри PYZ. Лицензии зависимостей находятся в `licenses`, иконок — в `_internal/assets/icons`, PresentMon — в `_internal/tools`. Сохраните эти файлы при распространении. Подробнее: `THIRD_PARTY_NOTICES.md`.
